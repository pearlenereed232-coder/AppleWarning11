# Apple Support Landing Page

A responsive Apple Support landing page with popup dialogs and phone call triggers.

## 🚀 How to Run Locally

```bash
npm install
npm start
```
Then open `http://localhost:3000` in your browser.

## ☁️ Deployment on Railway

1. Push this repository to GitHub.
2. Log in to [Railway.app](https://railway.app/).
3. Click **New Project** -> **Deploy from GitHub repo**.
4. Select this repository. Railway will automatically detect Node.js, run `npm install`, and start the app on `$PORT`.
